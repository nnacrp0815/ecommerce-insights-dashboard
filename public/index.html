One row per order line, with identifiers, date, product, channel, quantity, amounts and currency. This uses a documented CSV contract, not an unmodified Shopify export.

The file stays in memory on this device. Reloading restores the sample data.

NO MYSTERY METRICS

Know what the numbers mean.

Net product sales
Quantity × unit price, minus line discounts and refunded sales. Shipping, taxes, fees and product costs are excluded. This is a sales report, not a profit or accounting statement.
Paid orders & average order value
Distinct paid orders, including fully refunded orders. Average order value is net product sales divided by that count. With a category filter, both measures use only matching lines and orders containing them.
Refunds
Refund amounts are attributed to the original order date. The file does not include a refund transaction date, so this is not a cash-flow report. Refund percentage uses sales after discounts, before refunds.
Comparisons
The immediately preceding period of equal length, using the same filters. Changes are unavailable when the earlier period falls outside the file’s observed date coverage or its baseline is zero.
Coverage & missing orders
Reports use only the rows supplied. The dashboard cannot detect omitted orders. Days within the date range without matching rows appear as zero sales. An import’s observed first and last dates do not prove that it is complete.
Product table
Units are quantities ordered, not units retained after returns. Orders containing a product are distinct counts and should not be added across products. Share is each product’s contribution to the current filtered net sales.
Private by default
No analytics, external fonts, account, upload endpoint or browser storage. Import data stays in page memory and is cleared on reload. Keep confidential CSV files out of public repositories.
